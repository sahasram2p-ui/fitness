# Fitness Assistant

A Flask + Google Gemini fitness and wellness chatbot.

Answers fitness-related questions only. It does not provide diagnosis,
medical treatment, or prescription advice.

Setup:
1. python -m venv venv
2. .\\venv\\Scripts\\Activate.ps1
3. pip install -r requirements.txt
4. Add your Gemini API key to .env
5. python app.py
6. Open http://127.0.0.1:5000
